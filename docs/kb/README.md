# Junk Yard Design Knowledge Base

Every junkyard app is a small piece of design practice. This KB is where that practice accumulates, so the tenth app starts smarter than the first.

## How it grows

- **Before designing an app**, read `design/` for the shared principles and anything relevant to the app's subject.
- **When you research something** (a technique, a browser feature, a font pairing, a pattern), write the findings into the matching `design/` note, with sources and the date checked. Create a new note if none fits.
- **When you ship or redesign an app**, add or update `apps/{slug}.md`: the art direction concept, the key decisions and why, and anything that did not work.
- Keep notes short and factual. Link sources. Date anything that can go stale (browser support, trends).
