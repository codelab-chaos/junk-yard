# AI model research (checked 2026-10-29)

Research behind the [AI Model Usage Guide](../../apps/ai-model-guide.md). Two logs, written by research subagents and kept with every source, conflict and rejected claim.

- [leonardo.md](leonardo.md): every Leonardo.ai model (image, video, audio, 3D), plans, token costs, relaxed mode, cost levers, retirements.
- [aggregators.md](aggregators.md): Krea, Magnific (was Freepik), OpenArt, Higgsfield, Firefly, Canva, Poe, Runway, Artlist, Luma, Midjourney, fal and Replicate; public leaderboards; direct API prices; evidence on attempts per keeper.

Biggest gaps: Leonardo publishes no per-model token table, and nobody publishes measured keeper rates. The guide labels both as estimates.
